# Security

Please do not report security problems in a public issue.

## How to report

Use either route. Both reach the same people.

- **GitHub:** [report a vulnerability privately](https://github.com/rasterandstate/fjord/security/advisories/new).
- **Email:** security@rasterstate.com

Include what you can:

- Which client is affected (Fjord Mobile or the fj CLI) and its version.
- What an attacker could do, and the steps to reproduce it.
- The kind of forge involved and its version, if that matters.

Remove access tokens, passwords, and private server addresses from anything you send, unless they are needed to show the problem.

## Scope

This policy covers the Fjord client apps. The full Fjord security policy, including the hosted platform, is at [fjord.sh/security](https://fjord.sh/security).

Problems in Forgejo, Gitea, or another forge itself should go to that project.
